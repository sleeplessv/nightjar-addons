# Nightjar add-ons

A Home Assistant add-on repository for Nightjar.

To install it, add `https://github.com/sleeplessv/nightjar-addons` under **Settings → Add-ons → Add-on Store → ⋮ → Repositories**.

CI writes everything else in this repository on each release. Don't edit `repository.yaml` or `nightjar/` by hand, because the next release overwrites them.
